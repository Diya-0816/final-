# User Management App

A basic Flask app for user registration and login management.

## Features
- Register/Login/Logout
- SQLite backend
- Password hashing with Werkzeug

## Setup
```bash
pip install -r requirements.txt
python app.py
```

## Gitflow Usage
- `main`: Stable code
- `development`: Active development
